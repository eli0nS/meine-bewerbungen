# Meine Bewerbungen

Read `docs/WORKFLOW.md` before changing application preparation or delivery. This repository contains only code and fictional examples. Runtime documents, profiles, browser sessions and logs live outside the checkout.

Every run is started by the person using the local interface. Only that interface may review and approve a concrete application. Preparation tools cannot approve or send. Changes to the destination, answers, cover letter, profile or attachments invalidate approval. An uncertain submission is never retried automatically. Test with the local fixture portal and fictional data.

For local setup and user-approved draft work, use the project skill at `.agents/skills/meine-bewerbungen/SKILL.md`.

For an installation request, follow [INSTALL.md](INSTALL.md) and run the appropriate setup yourself. A bare URL can be ambiguous. Installation requires local execution permission from the user in their client.
